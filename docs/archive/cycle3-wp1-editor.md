# WP1 — 상세 초안과 행동 정리

근거: cycle3-fix-prompts.md와 cycle3-critique-report.md.

## 변경

X/Esc를 같은 인라인 확인으로 연결했다. 저장하고 닫기/초안 유지/변경 버리기, 닫힌 초안 이어서 편집, 다른 항목 클릭 시 기존 초안 재개와 버리고 전환을 구현했다. 제목 입력 우선 포커스, 분리된 일정 입력, 종료/상태/체크 요약, 체크리스트 접힘, Ctrl+Enter 저장. 주요 저장·완료·더보기로 묶고 가짜 캡처 진입점을 제거했다. 저장 큐·초안 sequence·revision/epoch 경로를 유지한다.

## 검증과 비용

공통 검증과 구체 측정은 `cycle3-wp9-final-review.md`에 기록했다. Node 테스트 5→9, 브라우저/DB 자동 테스트 lane 추가 없음. Rust·SQLite 저장 규칙은 변경하지 않았다.

## 마지막 확인 담당에게

브라우저에서 저장/유지/버리기와 다른 항목 열기를 실제 조작했다. native 쓰기 실패·재시도와 프로세스 재시작 후 초안 복구는 미검증이다.
