## 변경

WP0–WP8을 구현하고 한 번의 보정 묶음으로 반응형 너비, 시간표 가용 높이, 15분 블록 최소 높이, 점유 눈금, 성공 알림을 수정했다. 초기 지적 F1–F8 중 승인 없이 가능한 범위를 처리했다. 상세창의 닫힌 초안 잠금, Inbox가 달력을 숨기던 문제, 내비게이션 활성 표시 불일치가 해소되었다. 세부 변경과 마지막 확인 사항은 `cycle3-wp0-foundation.md`부터 `cycle3-wp8-polish.md`까지 기록했다.

확정 B/D 스타일·외부 의존성·Rust/SQLite 저장 규칙을 유지한다. DESIGN.md와 .impeccable/design.json을 동기화했다. 원본 색 대응표는 cycle3-token-map.json이다.

## 검증과 비용

- 최종 `npm test`: **9/9**, 98.772ms. 기존 5개 유지, 순수 표시 모델 4개 추가. 첫 수정 후 측정은 106.1092ms였다. 단일 실행 간 시간 차를 성능 개선/퇴보로 해석하지 않는다.
