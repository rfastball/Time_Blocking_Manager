# React 도입 시험: 오늘 화면 (2026-10-10)

**브랜치:** `spike/react-today` · **진입점:** `spike.html` (`npm run dev` 후 `/spike.html?now=10:20`)
**목적:** 블록 중심 재설계 시안의 물리적 조작(들어서 옮기기, 레일 흡착, 완료 흡입, 스프링 재배치)을 React + dnd-kit + Motion으로 구현할 수 있는지, 기존 순수 로직과 저장 경계를 그대로 쓸 수 있는지 확인한다. 도입 결정은 이 결과를 보고 사용자가 한다.

## 구성

| 영역 | 선택 | 역할 |
|---|---|---|
| UI | React 19.3 + `@vitejs/plugin-react` 5.2 | Vite 7을 유지하기 위해 플러그인 5.x(6.x는 Vite 8 필요) |
| 드래그 감지 | `@dnd-kit/core` 6.3.1 | 포인터 감지, 들린 사본(DragOverlay), 내려놓기 애니메이션. 정렬(sortable)은 쓰지 않는다 |
| 움직임 | `motion` 14.1 (`motion/react`) | 속도를 이어받는 스프링, 완료 흡입, 착지, 걸쇠, 셔터 |
| 배치 계산 | 기존 `flow.ts`·`today.ts`·`time-axis.ts`·`placement.ts` | 수정 없이 재사용 |
| 저장 | 기존 `SaveQueue` + Rust `mutate`, 브라우저는 `preview.ts` | 응답 후에만 반영. 드롭한 블록은 응답까지 그 자리에 머물고 실패하면 되돌아감 |

`main.ts`에 있던 브라우저 미리보기 변경 함수는 `src/preview.ts`로 옮겨 기존 앱과 시험 화면이 함께 쓴다. 날짜 보조 함수는 `src/dates.ts`에 둔다.

## 확인한 것

헤드리스 Edge에 CDP로 실제 마우스 입력을 넣어 확인했다(`?now=10:20`, 미리보기 지연 120ms).

| 장면 | 결과 |
|---|---|
| 10:20에 첫 블록 완료 | B 10:20–11:05, C 11:05–11:35, D 13:00–14:00. 재설계안 §10 셋째 행과 같다. 수거함 2건, 기준 10:20 |
| 미계획 블록을 B·C 사이 본문에 놓기 | 들고 있는 동안 빈칸이 생기고 뒤 블록이 비켜 남. 놓은 결과가 미리보기와 같다 |
| 유동 블록을 레일 15:30에 대기 | 15분 칸에 붙고 고정 재질·열린 걸쇠·시각 표시. 놓으면 15:30–16:00 고정 |
| 레일의 점심 시간에 대기 | 붉은 테두리와 ‘점심(작업 불가)과 겹침’. 놓아도 변화 없음 |
| 손잡이로 45분 → 75분 | 뒤 블록이 다시 놓이고 들어가지 못한 블록은 점심 뒤·워크숍 뒤로 이동 |
| 기존 앱(`index.html`)에서 완료 | 추출 전과 같은 재배치. 콘솔 오류 없음 |

`npx tsc --noEmit`, `npm test`(26건), `npm run build`(두 페이지) 통과. 시험 화면 번들은 434KB(gzip 140KB)다.

## 발견한 제약

- **dnd-kit은 transform을 무시하고 위치를 잰다.** 블록을 `transform`으로 배치하면 들린 사본이 공간 맨 위를 기준으로 그려진다. 블록 위치는 `top`으로 두고 transform은 흡입·착지 같은 순간 효과에만 쓴다.
- **드래그 시작 시 레이아웃이 바뀌면 사본이 어긋난다.** 드래그 시작에 상세 패널을 바꾸면 미계획 카드가 밀려 사본 기준점이 틀어진다. 선택은 놓은 뒤에 바꾼다.
- **가려진 창의 브라우저 탭은 `hidden`이 되어 타이머·애니메이션이 멈춘다.** 자동 검증은 헤드리스 브라우저로 한다.

## 남은 것

- 키보드로 드래그하기(dnd-kit KeyboardSensor)는 넣지 않았다. 지금은 Alt+↑/↓, 버튼, 손잡이 화살표로만 키보드 조작한다.
- Tauri 창에서 실제 SQLite로 확인하지 않았다. 코드 경로(`invoke('load'|'mutate')`)는 있지만 Tauri 창은 아직 `index.html`을 연다. 설치 파일 빌드도 하지 않았다.
- 편집 초안 보존, 종료 전 저장, 한글 조합 처리(입력 1곳만 적용)는 시험 범위 밖이다.
- 미계획 목록의 `layout` 애니메이션이 진행되는 동안 카드 밖으로 잠깐 넘치는 장면이 있다.
