# BLOKKY 직접 조작 참고 조사

상용 제품의 공식 도움말을 확인해 달력에 작업을 배치하고 조정하는 상호작용을 비교했다. 여기서는 제품이 문서화한 사실과 BLOKKY에 적용할 제안을 구분한다.

## 확인한 제품 동작

- **Sunsama — 작업 배치와 시간 조정:** 작업 목록에서 달력의 원하는 시각으로 작업을 드래그해 timebox를 만든다. 이미 배치한 세션은 달력 블록의 크기를 조절하거나 세션 팝오버에서 조정한다. 기존 작업에 다른 날 세션을 추가하는 것도 팝오버에서 가능하다. [Timebox 작업 배치 안내](https://help.sunsama.com/docs/usage-guides/timeboxing/timeboxing-how-to-timebox/)
- **Sunsama — 작업 메모:** 작업에는 생각과 진행 내용을 적는 서식 있는 메모 필드가 있다. 작업을 만들면서 바로 상세를 열 수도 있다. [작업 생성 및 속성 안내](https://help.sunsama.com/docs/usage-guides/tasks/creating-tasks/)
- **Sunsama — 일정 범위와 분할:** 기본 작업 시간과 채널별 일정을 설정할 수 있고, 자동 배치는 해당 일정 및 바쁜 달력 이벤트를 고려한다. 자동 배치가 긴 작업을 여러 시간 블록으로 나눌 수 있으며, `Shift+X`는 분할을 막는다. [자동 배치 안내](https://help.sunsama.com/docs/usage-guides/timeboxing/timeboxing-auto-scheduling/)
- **Google Calendar — 주간 근무 시간과 날짜별 항목:** 요일별 근무 시간에 하루 중 여러 구간을 설정할 수 있다. 특정 날짜의 문서화된 override는 근무 위치 변경이며, 별도로 휴가(OOO) 기간/시간과 반복 옵션을 설정할 수 있다. 이 도움말은 날짜별 근무시간 변경 기능을 확인해 주지는 않는다. [근무 시간·위치 및 OOO 안내](https://support.google.com/calendar/answer/7638168?hl=en-7)

## BLOKKY에 적용할 제안

- 미계획 작업을 달력 빈 시간으로 끌어 놓아 배치하고, 블록 가장자리 손잡이로 길이를 조정한다.
- 블록 제목을 누르면 같은 작업의 메모와 세부 정보를 연다. 목록과 배치된 블록은 동일한 작업을 가리킨다.
- 분할 가능한 시간 블록 안에 조절 경계를 두고 드래그 또는 키보드로 분할 지점을 정한다. 자동 배치 분할은 제품 범위에 포함하지 않는다.
- 주간 근무 규칙은 유지하고 BLOKKY 고유 기능인 날짜별 시간 변경·조퇴·휴가 예외를 별도 표현한다. 예외에는 반복 일정으로 복원하는 동작을 둔다.
- 조작은 화면 자체에서 알아볼 수 있도록 블록, 시간 눈금, 손잡이와 날짜 예외 상태를 표시한다. 반복해서 설명하는 안내 문구에 의존하지 않는다.

Sunsama의 외부 달력 연동이나 자동 배치 정책을 BLOKKY의 요구사항으로 간주하지 않는다. 위 제안은 종이 계획표처럼 직접 시간 블록을 다루는 로컬 플래너에 맞춘다.
